# Insider Threat Use Case

## Project Overview
This project documents a simulated insider threat investigation based on unusual user activity. The aim was to practise identifying suspicious behaviour, reviewing user activity logs, creating detection logic, and documenting findings in a SOC-style report.

## Scenario
A simulated alert was triggered after an employee accessed sensitive files outside normal working hours and downloaded a large number of documents shortly before leaving the organisation. The activity was reviewed to determine whether it could indicate insider threat behaviour or data exfiltration risk.

## Skills Practised
- User activity log review
- Insider threat indicator analysis
- Data exfiltration risk assessment
- Unusual behaviour detection
- Access review
- Detection logic creation
- SOC-style reporting
- Remediation recommendations
