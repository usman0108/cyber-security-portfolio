# IoC Enrichment Case

## Project Overview
This project documents a simulated Indicator of Compromise enrichment investigation. The aim was to practise reviewing raw IoCs, defanging indicators, adding context, assessing risk, and documenting findings in a SOC-style report.

## Scenario
A simulated endpoint alert identified suspicious activity involving a malicious document, suspicious outbound connection, unknown executable, and suspicious domain activity. The raw indicators were reviewed and enriched to help determine risk and recommended response actions.

## Skills Practised
- Indicator of Compromise review
- IoC defanging
- Threat intelligence-style enrichment
- IP, domain, URL and hash analysis
- Risk rating
- SOC investigation documentation
- Remediation recommendations

## Tools / Concepts Used
- IP address analysis
- Domain analysis
- URL review
- File hash review
- Endpoint activity review
- Threat intelligence concepts
- Incident response process
