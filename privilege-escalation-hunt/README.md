# Privilege Escalation Hunt

## Project Overview
This project documents a simulated privilege escalation investigation using Windows security event logs. The aim was to practise identifying suspicious account activity, reviewing privilege changes, creating basic detection logic, and documenting findings in a SOC-style report.

## Scenario
A simulated alert was triggered after a standard user account was added to a privileged administrator group. Additional events showed failed logins, a successful remote login, group membership changes, special privileges assigned, and suspicious PowerShell activity.

## Skills Practised
- Windows security event log review
- Privilege escalation investigation
- Suspicious account activity analysis
- User and group change monitoring
- PowerShell activity review
- Detection logic creation
- SOC-style reporting
- Remediation recommendations

## Tools / Concepts Used

- PowerShell command review
